# Car Rental Mobile App 🚗

A Flutter-based mobile application for car rental management. The app allows customers to browse cars, make bookings, manage reservations, and track booking status. It also provides dedicated dashboards for employees and managers.

## Features

### Customer
- User registration and login
- Browse available cars
- View car details
- Check car availability
- Book and cancel reservations
- Manage personal profile
- View booking history
- Receive notifications
- Report car accidents
- Simulated payment processing

### Employee
- Employee dashboard
- View and manage customer bookings
- Approve or decline booking requests
- Check cars in and out
- Update car status
- Add notes to bookings
- View daily statistics

### Manager
- Manager dashboard
- Manage cars (add, edit, delete)
- Manage employees
- View and manage bookings
- Approve and reject bookings
- Manage accident reports
- View statistics and reports

## Technologies Used

- Flutter

## Project Structure

- `lib/` – Flutter application source code
- `lib/pages/` – Application screens and dashboards
- `lib/services/` – API and application services
- `lib/models/` – Data models
- `api/` – PHP backend and API endpoints
- `assets/` – Application assets
- `test/` – Application tests

## Getting Started

### Prerequisites
- Flutter SDK
- Dart SDK
- PHP
- MySQL
- Android Studio or an Android device

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/DoniaAssi/car-rental-app-flutter.git
   ```

2. Navigate to the project directory:
   ```bash
   cd car-rental-app-flutter
   ```

3. Install dependencies:
   ```bash
   flutter pub get
   ```

4. Configure the PHP backend and MySQL database.

5. Update the API base URL in the Flutter application to match your backend environment.

6. Run the application:
   ```bash
   flutter run
   ```
